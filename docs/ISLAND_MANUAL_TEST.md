# OpenYoink Island 真机验收

本清单只用于人工验收。自动验证限定为 `xcodebuild build` 和
`xcodebuild test ... -only-testing:OpenYoinkTests`，不运行 UI 自动化。

## v1.7.1 / build 36：网页媒体恢复

- 在 ego 播放 Bilibili 视频，切换视频与播放/暂停后，展开“正在播放”应显示当前会话。
- 有效会话暂时缺少标题时显示浏览器名称；标题到达后更新，播放按钮与可用的进度信息保留。
- 打开媒体页会补读一次系统状态；连续点击只保留一个进行中的补读，不产生后台轮询。
- 补读期间收到更新的视频信息时，旧补读结果不能覆盖它；视频结束后的空会话仍应清除显示。
- 模块关闭、锁屏或睡眠后停止媒体进程；恢复后旧进程的回调不能干扰新的媒体源。
- 若浏览器完全未向 macOS 注册媒体会话，补读仍可能为空；本修复不读取网页内容或浏览器 Cookie。

## v1.4.0 / build 19

- 升级已有偏好后仍保持左侧、右侧或自定义布局；只有在设置中选择“刘海 Beta”才进入 Island。
- 内置刘海屏：紧凑态与摄像头区域融合，点击、`⌘⇧Space`、`Esc`、固定与收起均正常。
- 无刘海屏和外接屏：菜单栏下方显示顶部胶囊；跨屏移动鼠标或拖拽后 Island 跟随目标屏幕。
- 默认从任意应用拖到屏幕顶部中央时 Island 保持紧凑；开启“拖拽文件靠近顶部时展开灵动岛”后才展开 Shelf，取消拖拽恢复原状态，成功落入保持展开。
- 侧边暂存架默认保持收起；普通鼠标靠近拉环不会展开，单击拉环才会打开。
- 开始拖动文件时侧边暂存架不会立即遮住内容；拖到对应屏幕边缘短暂停留后才展开，成功放入后保持展开。
- 侧边设置“拖入后保持展开”默认开启（含旧版升级）；关闭后，仅拖拽自动唤出的侧边暂存架在投放结束后收起。手动打开、拖出后隐藏和清空后隐藏不受该设置改变。
- 连续拖拽、取消或在其他应用放下时，上一轮结束回调不能关闭下一轮或手动重新打开的侧边暂存架；顶部 Island 的成功投放行为不变。
- 按住拉环沿屏幕边缘拖动时可调整位置，过程中不会误触发暂存架展开。
- 透明区域不拦截菜单栏；多个 Space、全屏、睡眠唤醒、插拔显示器后位置正确。
- Shelf 的 Stack、Quick Look、多选、快捷动作、拖入和拖出与经典模式一致。
- 传输失败可恢复、重试和关闭；计时器预设/自定义、暂停、继续、重置及重启恢复正常。
- 电池 20%/10% 阈值去重，插拔电源显示短暂活动；无内置电池时显示“不适用”。
- VoiceOver 可读出模块与按钮状态；Reduce Motion 下无弹簧或尺寸形变；中英文无明显裁切。

## v1.4.1 / build 20

- “正在播放（实验性）”默认关闭，首次启用会显示风险说明。
- 分别测试 Apple Music、Spotify 和浏览器媒体；播放/暂停、上一首、下一首只在能力可用时启用。
- helper 不可用或输出异常时最多按 1、2、4 秒重试，随后降级到 Apple Music / Spotify AppleScript。
- AppleScript 仅在实验模块开启且 helper 不可用时请求自动化权限；拒绝权限不会影响其他模块。
- 播放器退出、媒体数据畸形和 helper 崩溃只让媒体模块进入不可用状态，Shelf 仍可正常拖放。

## v1.5.0 / build 21

- 计时器支持专注、短休息和长休息模式，开始、暂停、继续、重置与跨启动恢复正常。
- 专注完成后写入本地热力图；周切换、日期统计、连续天数和空记录状态正确。
- Island 可选择主显示器、自动跟随鼠标或固定到指定显示器；显示器断开后安全回退，重连后恢复。
- 展开 Island 后可直接进入设置；左右控制数量与间距保持平衡，按钮不会贴边或遮挡模块内容。
- Island 紧凑态悬停反馈持续到鼠标离开，不会只闪现一瞬间。

## v1.6.2 / build 24

- 普通鼠标靠近侧边拉环不展开；单击拉环仍可打开暂存架。
- 按住拉环可沿屏幕边缘调整位置，过程中不会误触发暂存架展开。
- 从 Finder 等应用拖着文件靠近对应屏幕边缘时，暂存架自动展开并可接收投放。
- 设置中不再显示与上述交互冲突的“悬停边缘拉环时预览暂存架”开关。

## v1.6.3 / build 25

- 电池模块约每 2 秒刷新当前功率；充电显示正值，放电显示负值，插拔电源后的过渡状态与 macOS 电池状态一致。
- 功率波形保留最近两分钟、最多 60 个采样点，零轴、动态量程、当前值、平均值和最新采样点均正常更新。
- 电池模块关闭后停止轮询；重新启用后重新开始采样，不产生重复任务或持续增长的历史数据。
- 系统状态中的电池摘要同步显示功率；功率字段不可用时只隐藏瓦数，不影响电量、状态或其他系统指标。
- 无内置电池时显示“不适用”；实现不读取 SMC、精确温度、传感器或风扇接口。
- 中英文文案、VoiceOver、Reduce Motion 以及刘海屏和无刘海屏布局无裁切或重叠。

## v1.6.1 / build 23

- 顶部保持“设置 + 五个模块位置”；空位置可直接选择模块，模块库支持启用、停用、固定、取消固定和拖动排序。
- 新安装默认固定暂存架、计时器和系统状态；旧用户迁移后不自动开启系统状态，未知模块 ID 不丢失。
- 侧边拉环停留后预览暂存架，移入暂存架后保持；点击、快捷键、拖放和开始拖出会提升为持久展开。
- 系统状态显示 CPU、内存、网络、磁盘、电池、热状态与三个前台应用；排行榜可在剩余高度内上下滚动。
- 内存数值不重复计算 inactive/cache 与压缩页；告警只响应 macOS 内存压力事件，不按占用比例误报。
- 系统状态只读；告警不结束进程、不清理磁盘、不控制风扇，也不读取私有传感器或精确温度。
- 左右边缘、多个显示器、多个 Space、全屏、睡眠唤醒、网络接口切换、VoiceOver 与 Reduce Motion 均人工复核。

## 发布前证据

### v1.6.4 / build 26

- “快速访问”默认关闭且未固定；启用后可从模块库临时打开或固定到顶部位置。
- 添加按钮在普通和悬停状态下与黑色背景保持清晰对比，Reduce Motion 下不做缩放动画。
- 选择或拖入文件夹后可双击、Return 或右键打开；默认操作跟随当前 macOS 默认文件管理器，Finder 与 QSpace 切换后无需重启或重新收藏。
- 收藏支持排序、重命名、重新定位和移除；普通文件不会误落入暂存架，移除收藏不会删除真实文件夹。
- bookmark 损坏或目录离线时只标记单个收藏不可用，损坏的持久化文件会隔离保留且不会覆盖。

### v1.6.5 / build 27

- 在 Chrome 等浏览器中拖动标签页靠近侧边暂存架所在屏幕边缘时，暂存架保持收起，不遮挡标签页拖动。
- 拖动网页链接、文本或纯图片数据靠近屏幕边缘时同样不自动展开；手动打开暂存架后仍可正常接收这些内容。
- 从 Finder 拖动真实文件或文件夹、从 Photos/Mail 等来源拖动文件承诺时，靠近对应屏幕边缘仍可展开并完成投放。
- 按住侧边拉环调整位置仍会抑制展开；左侧、右侧、多显示器与 Reduce Motion 行为保持不变。

### v1.6.7 / build 29

- 内置刘海屏紧凑态两侧各为 40pt，菜单栏相邻图标的可见性与点击需人工核对；图标进一步增多时仍可能发生重叠。
- 计时文字保持单行；正在播放的控制按钮与视觉区域对齐。外接无刘海屏的胶囊尺寸保持不变。

### v1.6.6 / build 28

- 顶部 Island 默认不响应拖拽靠近，浏览器标签页在顶部移动时保持紧凑；设置中主动开启独立开关后，拖拽靠近顶部中央才展开 Island Shelf。
- 侧边暂存架继续支持真实文件和文件承诺靠近屏幕边缘后展开，不受顶部开关影响。
