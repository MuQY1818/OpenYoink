# 剪贴板历史与应用图标开发版

此功能已随 v1.6.9 (33) 发布。本文记录实现边界、隐私行为与验收状态。
基于公开版 v1.6.8 (31)，不包含另一个工作树中未提交的收藏文件夹投递实验。

## 范围与隐私

- 剪贴板历史默认关闭；开启或恢复时只记录下一次复制，不追溯已有剪贴板。
- 支持普通文字、HTTP(S) 网址、单帧 PNG/TIFF 图片；不接收文件 URL。
- 支持菜单栏窗口与可选灵动岛模块。模块只负责展示，启用模块不会自动开启记录。
- 支持搜索、内容预览、复制、加入暂存架、删除、清空、暂停和恢复。
- 最多 30 条，保留 1 / 7 / 30 天，默认 7 天；文字单条 256 KiB、图片单条
  5 MiB、全部内容 20 MiB；图片尺寸上限 16384，像素总数上限 3200 万。
- 数据保存在沙箱 Application Support/OpenYoink/clipboard-history.json，文件权限 0600。
  **这是本机明文文件，不是加密存储，也不会上传或同步。** 清空删除该文件，不保留历史备份。
- 跳过 `ConcealedType`、`TransientType`、`AutoGeneratedType` 及常见密码管理器标记。
  未标记的密码/令牌等敏感文字仍可能被记录，不能保证自动识别全部密码。
- 采样时前台应用在现有忽略列表中则不记录；这不是对实际复制来源的可靠归因。
- 每 750ms 只比较剪贴板 changeCount，内容发生变化后才读取；关闭或暂停取消采样任务。
- 关闭记录保留已存历史；退出等待最新快照落盘；损坏/未知版本文件不会被自动覆盖。
- 不模拟粘贴，不新增辅助功能权限；复制按钮只恢复系统剪贴板。添加到暂存架使用独立命名
  剪贴板，不改变系统剪贴板。

## 图标修复

原主图为 RGB，外角白色不透明，直接缩放会在不自动遮罩的 Launchpad 中呈现大方形。
生成脚本保留原图案，移除主图白色外缘，烘焙透明留白和圆角，1024 画布可见宽度 824。
运行 `swift Scripts/generate-icon.swift` 重建全部槽位，并检查透明四角和 70%–85% 的视觉占比。

## 手工验收

不运行 UI 自动化或 Computer Use；以下交互留给使用者检查。

1. 在 macOS 15.8.1 Launchpad 与 Finder 预览中比较图标大小/圆角，排除旧图标缓存。
2. 默认关闭时复制不产生记录；开启后旧剪贴板不入库，新文字/网址/截图入库。
3. 搜索中文与英文、滚动 30 条历史、预览长文字与图片，再复制粘贴核对内容。
4. 暂停复制后恢复，不追溯暂停时内容；关闭灵动岛后，已开启的记录仍正常工作。
5. 密码管理器、已忽略应用、文件复制不入库；非标记敏感文字应手工暂停后再复制。
6. 加入暂存架保持当前系统剪贴板；清空/删除后退出重开，数据不能恢复。
7. 缩短保留时间立即淘汰到期数据；关闭记录仍能查看已有历史。
8. 灵动岛搜索框的 Cmd+A/C/V、Delete 不得作用于背后的暂存架项目；Esc 收起。
9. 检查深浅色、VoiceOver、Reduce Motion、小屏幕与外接显示器。
10. 连续复制图片、重开窗口、睡眠唤醒后检查内存和采样；当前机器不是 Issue 作者的
    macOS 15.8.1，启动台表现需由该环境补验。

试用产物采用独立 bundle ID `com.weijue.OpenYoink.ClipboardPreview`，正式软件与数据不被替换。
测试前先退出正式 OpenYoink，避免两个菜单栏/灵动岛同时显示。试用版的数据和设置为空是预期的。
打包后的试用 app 清空 `SUFeedURL`，不会从正式更新源自动替换为公开版本；源码中的正式更新源保持不变。

## 深色样式修复试用版 (33)

用户反馈剪贴板模块在黑色灵动岛内出现黑字及异常开关。修复包括：

- 岛内文字沿用 `IslandVisualStyle` 白色/次级白色；普通历史窗口继续使用系统语义颜色。
- IslandRootView 显式传递深色环境，Island 的 AppKit 面板指定 `darkAqua`，使原生开关、
  搜索框、菜单及 SwiftUI 内容主题一致；经典侧边暂存架不固定主题。
- 更新后的试用包位于 `build/ClipboardThemePreview/OpenYoink.app`，版本 `1.6.9 (33)`。
  bundle ID 与上一试用包一致，设置与历史保留；正式软件没有被替换。
- 重跑 622 项应用单元测试、4 项核心测试均通过，Debug/Release 通用构建及签名检查通过。
- 未运行 UI 自动化或 Computer Use，具体显示效果由用户手工验收。
