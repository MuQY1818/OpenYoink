# OpenYoink 1.7 日常操作改进

本地开发版：1.7.0（35）。尚未推送或发布。

## 使用入口

- 剪贴板：菜单栏或 `⌘⇧V` 打开，可在通用设置更改快捷键。搜索旁可筛选全部、收藏、文本、链接和图片；每条的星标用于收藏。
- 历史：普通条数可选 30、100、300，默认 30；收藏最多 30 条，不按天过期。全部内容仍有 20 MiB 上限，删除收藏或清空历史会删除对应记录。
- 暂存架：侧边与 Island 共用搜索和类型筛选；`⌘F` 聚焦搜索。手动移除可用工具栏撤销或 `⌘Z`，最多保留 20 次本次运行的操作。
- 快速访问：将文件拖到收藏卡片上复制，将文件夹拖到“添加收藏”区域创建收藏。原文件及暂存架卡片保留。重名可保留两份、跳过或取消，不提供覆盖。
- 预设：通用设置中的文件暂存、文件与剪贴板、完整工具箱。确认后调整模块与展开方式，不更改剪贴板记录授权，也不删除数据。
- 展开设置：侧边与 Island 的悬停、拖拽展开集中于触发器页。顶部拖拽展开仍默认关闭。

## 存储与恢复

旧版剪贴板 JSON 可以直接读取。下次保存时写入版本 2 的索引；图片单独保存于 `ClipboardImages`，索引写入成功后才回收未引用附件。损坏或未知版本的索引不自动覆盖。升级后的剪贴板格式无法由 1.6 直接读取，降级前应备份整个应用数据目录。

收藏优先占用空间；存储上限不足以接收新内容时显示提示。收藏不随普通历史条数和保留期限淘汰。

撤销只恢复暂存架引用，不逆转文件交付、废纸篓操作或外部删除。托管文件成功交付时，其相关撤销记录失效；撤销中的文件和正在复制的文件参与“清理未使用文件”的保护集合。

## 灵动岛与采样

公共标题、开关、选中颜色和进度控件集中于 `IslandChrome.swift`。模块切换保留同一顶部和外框，模块内容在边界内裁切；电池、计时器和音乐使用公共纵向滚动容器。

电池：展开选中时 2 秒，后台 15 秒，低电量模式或严重热状态 30 秒；电源通知仍及时更新。AppleScript 音乐备用源：展开 2 秒，后台 5 秒，无播放器或节能时 15 秒。本地音乐 helper 使用事件流。睡眠与锁屏暂停系统、电池、音乐和剪贴板采样；唤醒后恢复已启用模块，不补录锁屏期间的剪贴板。

系统原有的 1／5／15 秒采样策略保留。展开上下文变化会重新调度采样。计时器保留原来的结束时间语义。

## 验证

完整应用单元测试、Foundation 包测试、Debug 与 Release 构建；Release 检查 arm64／x86_64、签名和 App Sandbox。原生拖放、VoiceOver、多显示器、Space、锁屏与睡眠唤醒需人工验收。本次不使用 Computer Use 或 UI 自动化。

已通过：应用完整单元测试 642 项（无失败、无跳过）、Foundation 包测试 4 项、Debug 构建、arm64／x86_64 Release 构建、发布签名检查、Sandbox 权限检查、网站构建与 SEO 检查、`git diff --check`。

本地试用包位于 `build/WorkflowUpgrades/OpenYoink-1.7.0-preview.zip`。签名沿用现有社区版的 ad hoc 方式，按现有发布脚本逐个签名 Sparkle 嵌套组件，再签主程序；未改变安装流程或进行 Apple 公证。

只读空闲测量脚本：`swift Scripts/profile-idle.swift PID 300`。它采集进程 CPU 时间差、物理内存占用、磁盘 IO、空闲和中断唤醒，不读取文件内容或剪贴板。比较应保持模块、音乐播放、展开状态与机器负载一致。
