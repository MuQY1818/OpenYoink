# 文件安全与隐私

## 普通文件：引用原位置

普通拖入文件或文件夹时，OpenYoink 保存 security-scoped bookmark，不会复制一份原文件。移除卡片或设置“拖出后移除”，都不会删除原文件。

如果原文件被移动、删除或外接磁盘离线，卡片会显示不可用。已经存在 bookmark 但解析失败时，OpenYoink 不会回退到一个未经授权的旧路径。

## 文本、图片与富内容

| 内容 | 存储方式 |
|---|---|
| 纯文本、链接 | 写入暂存架数据 |
| 图片、HTML、RTF | 在应用沙箱的托管目录中物化为文件 |
| 联系人、日历、邮件 | 来源提供可读数据时物化为 `.vcf`、`.ics`、`.eml` |

移除卡片后，失去引用的物化文件会在安全清理时删除。可以在“设置 → 存储”中查看数据目录并清理未使用文件。

## ⌘ 拖入：托管移动

按住 `⌘` 拖入文件或文件夹，会执行以下顺序：

1. 复制到 OpenYoink 沙箱的托管目录。
2. 确认副本存在且可用。
3. 把原文件移入废纸篓。

任一步失败都会保留原文件，并回退为普通引用。托管项目成功拖出后，目标收到文件，暂存卡片与托管副本随即删除；取消或失败时则保留以便重试。

::: danger 注意废纸篓
托管移动的原文件会进入废纸篓。只有在废纸篓尚未清空时，原文件才可能恢复。
:::

## 本地数据与联网

- 启用 App Sandbox。
- 不需要账号，不包含分析统计或遥测。
- 默认更新检查会访问 GitHub Pages 与 GitHub Releases，可在设置中关闭。
- 剪贴板历史默认关闭；未开启时只有执行“暂存剪贴板”才读取当前剪贴板。开启历史后仅记录后续复制的文本、HTTP(S) 网址和图片，内容保存在本机沙箱内，不上传或同步。
- 正在播放模块不访问在线封面、歌词或媒体服务。
